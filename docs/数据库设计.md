# 数据库设计

> SQL Server 存结构化业务数据，Neo4j 存知识图谱。不可混放。
>
> **示例数据口径**：本文档与 `server/sql/init.sql` 中的示例数据（如 `ch_01=一元二次方程`、`kp_001=一元二次方程的定义`）仅用于结构与接口示意，与真实演示数据**不是同一套**。实际导入 Neo4j 的演示数据以 `kg-data/data/knowledge_points/*.csv` 为准（其 `ch_01=一元一次方程`，共 22 知识点）。跨库引用（`q_matrix` / `user_kp_mastery` 的 `knowledge_point_id`）必须与 Neo4j 实际节点 ID 一致。

## 二、Neo4j 图模型

### 2.1 节点：KnowledgePoint

```
(:KnowledgePoint {
    id: "kp_001",              // 业务 ID（与 SQL Server 保持一致）
    name: "一元二次方程的定义",  // 知识点名称
    description: "...",        // 详细描述
    difficulty: 0.3,           // 难度 0.0-1.0
    estimated_time: 25,        // 预估学习时长（分钟）
    chapter_id: "ch_01",       // 所属章节 ID
    sort_order: 1              // 同章节内排序
})
```

### 2.2 关系：PREREQUISITE

```
(:KnowledgePoint {id: "kp_000"})
    -[:PREREQUISITE]->
(:KnowledgePoint {id: "kp_001"})
```

语义：kp_000 是 kp_001 的**前置依赖**（学 kp_001 之前必须先掌握 kp_000）。

**规则**：
- 有向，从前置指向后继
- 不可成环（拓扑排序会检测）
- 多对多

### 2.3 关系：BELONGS_TO

```
(:KnowledgePoint {id: "kp_001"})
    -[:BELONGS_TO]->
(:Chapter {id: "ch_01", name: "一元二次方程"})
```

> Chapter 节点可选。如果章节信息已完整存在 SQL Server，也可以不建 Chapter 节点，仅用属性 `chapter_id` 关联。

## 三、数据流向总览

```
┌──────────────────────────────────────────────────┐
│                    SQL Server                      │
│                                                    │
│  users ──┬── answer_records                        │
│          │       │                                  │
│          │       └──→ 输入 DINA（结合 Q矩阵）        │
│          │                    │                     │
│          ├── diagnosis_sessions ←── DINA 输出       │
│          │       │                                  │
│          └── user_kp_mastery ←── 实时更新           │
│                                                    │
│  questions ──┬── q_matrix ──→ 关联 Neo4j 知识点     │
│              │                                      │
│              └── options（JSON 列内）                │
│                                                    │
│  check_ins / achievements / weekly_reports          │
└──────────────────────────────────────────────────┘
                          │
                          │ knowledge_point_id 关联
                          ▼
┌──────────────────────────────────────────────────┐
│                     Neo4j                          │
│                                                    │
│  (:KnowledgePoint)                                 │
│       │                                            │
│       ├── [:PREREQUISITE] → (:KnowledgePoint)      │
│       │                                            │
│       └── [:BELONGS_TO] → (:Chapter)               │
│                                                    │
│  负责：图谱拓扑、前置依赖查询、路径规划             │
└──────────────────────────────────────────────────┘
```
