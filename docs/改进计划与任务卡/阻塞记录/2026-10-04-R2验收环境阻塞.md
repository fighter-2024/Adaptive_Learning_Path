## 6. 解阻结果（2026-10-05 复核）

### 6.1 根因更正：不是 SQL Server 的加密/证书配置

M3-R2 返修说明中记录的「需修复实际 SQL Server 实例的加密/证书握手配置并重启服务」不成立。实测证据：

| 检查项 | 实测值 | 结论 |
| --- | --- | --- |
| `SuperSocketNetLib\ForceEncryption` | `0` | 未开启强制加密，无需关闭 |
| `SuperSocketNetLib\Certificate` | 空 | 未指定用户证书 |
| ERRORLOG 启动行 | `A self-generated certificate was successfully loaded for encryption.` | 实例使用自生成证书，属默认正常状态 |
| `sqlcmd -S localhost -E`（不请求加密） | 成功，读到 11 张业务表 | 服务端接受非加密连接 |
| 以 `app.config.settings` + `app.db.sqlserver` 直连 | 成功 | 项目侧配置本身可用 |

结论：实例未强制加密。只有当客户端**自行要求加密**（`Encrypt=yes`）时，才会因自生成证书不受信任而握手失败并报 `证书链是由不受信任的颁发机构颁发的`。因此本项无需配置证书，也无需重启 SQL Server。

### 6.2 实际根因：8000 端口 FastAPI 进程的有效配置与 `.env` 不一致

- 旧进程（PID `37364`，启动于 `00:02:26`）持续返回 `sqlserver=false`。
- 复核 SQL Server ERRORLOG：该进程的健康检查**未在服务端留下任何登录记录**，说明失败发生在客户端侧、连接未到达实例——这与「服务端强制加密」的判断相反。
- 同机、同 Python、同 `.env` 下直接调用项目的 `settings` 与 `sqlserver` 模块连接成功，证明 `.env` 内容正确（`Encrypt=no`、`TrustServerCertificate=yes`、`Trusted_Connection=yes`）。
- **根因（2026-10-05 已复现确认，不再是推断）**：`pydantic-settings` 默认让**进程环境变量覆盖 `.env`**。任何会话残留的 `SQLSERVER_ENCRYPT=yes` + `SQLSERVER_TRUST_SERVER_CERTIFICATE=no` 都会静默生效，与实例的自生成证书握手失败。实验：以这两个环境变量启动 8099 端口实例，`/health` 精确复现 `sqlserver=false`，日志即 `08001 / 证书链是由不受信任的颁发机构颁发的 (-2146893019 = 0x80090325 SEC_E_UNTRUSTED_ROOT)`。

处置（2026-10-05 已完成，见 [交付记录](../../Delivery/2026-10-05-SQLServer连接反复失效根因与修复.md)）：

1. `server/app/config/settings.py` 新增 `settings_customise_sources`，把 `.env` 提到环境变量之前，使 `.env` 成为权威来源——**这才是让该故障不再复发的修复**；
2. 启动时打印不含密码的有效连接配置，健康检查失败时同时输出异常与有效配置，便于直接定位；
3. 终止旧进程并以 `python -m uvicorn app.main:app --host 127.0.0.1 --port 8000`（工作目录 `server/`）重启，输出重定向至 `server/.runtime/uvicorn.{out,err}.log`；
4. 修复后以同样的敌意环境变量重启 8099 实例，`/health` 返回 `status=ok`；`python -m pytest tests -q` 为 330 passed。

> 残余事项：**已于 2026-10-05 21:10 消除**。实例已配置受信任证书（指纹 `C53014E12F132CB8A9A1471510B848C73BF29478`，SAN 覆盖 `localhost`/`WBMSTR`/`127.0.0.1`），`Encrypt=yes` + `TrustServerCertificate=no` 与 `sqlcmd -N` 均已实测通过；`ForceEncryption` 保持 `0`。至此 `Encrypt` 的任意取值组合都能连接，第 6.2 节的复发模式从两端同时封堵。详见交付记录第 5 节。
