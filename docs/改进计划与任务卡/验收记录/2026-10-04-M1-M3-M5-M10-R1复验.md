## 2. 逐卡结论

### M1-R1：退回补证

已确认显式页面映射生效，生产构建中存在 Dashboard、KnowledgeGraph、Questions 独立分块；学生端认证静态检查和双平台构建通过。

未提交学生端、管理端的登录、刷新恢复、错误角色/失效 Token、退出登录以及 401/403/断网界面证据，也没有 M1-R1 独立交付记录。依据 M0 手册“缺少验证证据的交付直接退回”，不得仅凭构建通过判定完成。

### M3-R1：退回

focus 保留、数据库侧有界候选、外部直接前置锁定、掌握度分批和学生隔离等自动化用例通过。

仍存在跨截断窗口环路漏检：`graph_service.py` 只读取 `target.id IN $node_ids` 的前置边。如果完整图存在 `A → B → A`，但窗口只渲染 A，则查询只返回 `B → A`，`topological_sort` 看不到 `A → B`，接口会返回成功图而不是图数据库错误。M0 使用与当前查询返回结构一致的输入复现结果为 `cycle_error=False`。

此外未提交真实 Neo4j/SQL Server 下 tree、network、personalized、focus 小窗口、include_mastered=false、双学生隔离、查询次数及数据库故障响应证据。

### M5-R1：退回补证

`getRequestErrorInfo` 正式导出、401/403 分类、知识点字段与前置关系原子保存、保存确认、图谱节点/关系语义和批量结果展示均通过代码及自动化检查。

真实知识点/题目 CRUD、环路失败回滚、学生侧同步、Q 矩阵更新、批量部分失败、错误界面和图例截图全部未提交；交付记录也明确说明这些尚未采集。M5 最终结论还依赖 M3 通过，因此本轮不能通过。
