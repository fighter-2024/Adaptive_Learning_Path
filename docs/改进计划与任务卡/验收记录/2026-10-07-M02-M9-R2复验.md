## 4. P2 剩余 B：空白归一化正则多转义

`server/app/services/weekly_report_service.py` 的 `_normalize_summary` 使用 `re.sub(r'\\s+', '', summary)`，匹配字面反斜杠与 s，未消除普通空格；应按实际空白字符语义处理。

同一真实 20 秒 SQL 源、每例先使专用缓存失效，独立受控 provider 实测：

| 输入总结 | 预期 | 实际 |
|---|---|---|
| 本周没有有效的作答时 长记录。已记录作答时长20秒，不足1分钟。 | 矛盾声明降级 | degraded=false，错误原文被接受 |
| 本周已记录作答时长 20 秒，不足 1 分钟，按整分钟显示为 0 分钟。 | 正确事实可成功 | degraded=true，误降级 |

前者的“时 长”不能靠空白绕过否定检查；后者是正常的数字/单位空格，不应改变事实判定。这是同一归一化实现错误的两种结果，不扩展到无限自然语言审核。来源：`controlled_summary_validation` 最后两例。
