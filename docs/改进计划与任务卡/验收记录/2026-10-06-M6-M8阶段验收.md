## 3. M8 独立缺陷证据

复现命令（server 工作目录）：

```powershell
$env:PYTHONPATH='.'
python scripts/m01_verify_m8_config_null.py
```

使用实际 FastAPI 应用及配置路由的 `TestClient(raise_server_exceptions=False)`，只在独立进程覆盖管理员依赖，不访问真实账号/数据库。每个案例均恢复完整 settings 内存快照，不向 8000 共享服务发送非法更新。该脚本不能代替身份权限或真实库验收。

| PUT 请求体 | PUT HTTP / code | 内存改变 | 随后 GET HTTP / code |
|---|---|---|---|
| `{"path_weight_mastery":null}` | 500 / 50000 | 否 | 200 / 0 |
| `{"path_weight_profile":null}` | 200 / 40000 | **是，profile=null** | **500 / 50000** |
| `{"dina_em_max_iterations":null}` | 200 / 40000 | **是** | **500 / 50000** |
| `{"llm_timeout":null}` | 200 / 40000 | **是** | **500 / 50000** |
| `{"dina_em_max_iterations":null,"path_weight_profile":"m01-rejected-but-applied"}` | 200 / 40000 | **是，合法 profile 也被应用** | **500 / 50000** |

最后恢复后 GET 为 200。注意 200/40000 是业务拒绝；问题不是“HTTP 200 本身”，而是拒绝后配置已被改变。

根因：`SystemConfigUpdate` 把可选字段声明为 Optional，显式 null 进入 `model_dump(exclude_unset=True)`；权重直接 `float(None)`，其他字段直接 `setattr(settings, ...)`，然后才构建安全响应。模型校验报错发生时已有部分写入，路由捕获 ValueError 后不会回滚。

影响：管理员误传一个合法 JSON null 即可使配置 GET 持续失败；profile=null 还会使路径响应模型校验失败。DINA/LLM 参数被写成 None 会影响后续使用。不能只增加 TypeError 捕获或前端校验，必须在写入前完成后端完整校验，并保证拒绝不改变任何配置。
