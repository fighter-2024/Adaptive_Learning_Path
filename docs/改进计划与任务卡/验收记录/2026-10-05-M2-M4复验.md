## 3. M2 真实闭环证据

### 3.1 API 与数据库实证

使用临时真实学生 Token 完成以下链路：

1. `GET /api/student/questions?knowledge_point_id=kp_001&count=10` 返回正式题目，响应只含 `id/content/type/difficulty/options`，未泄漏答案和解析。
2. 对同一题分别提交正确答案 `A` 和错误答案 `B`，服务端分别返回 `correct=true/false`，并返回 `mastery_change`。
3. `exclude_done=true` 后，已完成的 `q_001` 不再出现在取题结果中。
4. SQL Server 实查：`answer_records=2`；掌握度为 `questions_done=2、correct_count=1`。
5. 清理后临时用户、答题记录和掌握度残留均为 `0`。

独立脚本结果摘要：

```text
take_question=True
safe_fields=True
correct_answer_result=True
wrong_answer_result=True
mastery_change_present=True
exclude_done=True
sql_answer_records=2
sql_mastery={questions_done: 2, correct_count: 1}
cleanup_remaining=0
```
