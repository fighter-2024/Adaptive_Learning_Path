## 2. M0 的职责与结论规则

M0 负责冻结范围、协调接口/模型/文件冲突、审查交付、执行独立验证、给出验收结论、生成返修卡，并维护 [任务总看板](README.md)。后续全链路验收也由 M0 负责。

执行者写“已完成”、勾选任务卡或提交 Delivery，均不等于 M0 通过。状态证据按以下方式识别：

- `验收记录/` 中的 M0 最终结论，是已通过状态的依据。
- `docs/Delivery/` 是执行者交付与验证说明，需要独立复核。
- 任务卡的勾选是执行者自查；M7 虽全部勾选，R1 复验仍有学习入口剩余缺陷，以 M7-R2 和最新验收记录为准。
- 旧 R1/R2 记录和阻塞记录保留历史，不用其中已解除的阻断覆盖后来的最终结论。

结论使用“通过 / 附条件通过 / 退回”。契约破坏、假数据、错误身份、数据泄露、核心闭环错误、回归失败不得记为通过。新增返修卡应精确限定剩余缺陷，保留已通过部分。

### 2.1 6.1 Sol 上下文与计费阈值提醒

- 每个 M0 验收窗口都必须关注本窗口的累计输入 token；接近或达到 `272K` 时，立即暂停继续堆叠大段材料并提醒负责人。
- 提醒中必须说明：超过 `272K` 输入 token 后，整个请求按 `2×` 输入/缓存、`1.5×` 输出计费；是否继续当前窗口或改开新窗口，由负责人决定。
- 未获得负责人选择前，不得把“继续在旧窗口追加长 diff/日志”作为默认方案。验收材料应按任务、文件或证据类型拆批读取，结论与必要证据及时写入仓库文档，降低窗口切换成本。
- 若当前运行环境不能精确显示累计 token，应在明显进入超长上下文、准备继续读取大批 diff/日志前提前提醒，不得以无法精确计数为由跳过提醒。

## 4. 已冻结的产品与技术范围

项目主题是“基于知识图谱的自适应学习路径规划与社交激励系统”。本轮的核心是：真实答题 → 掌握度/诊断 → 个性化路径 → 图谱和原因解释 → 管理端观察真实学习数据。

| 层 | 当前选择 |
|---|---|
| 后端 | Python FastAPI，Router/Service/Model 分层 |
| 关系数据库 | SQL Server：用户、题目、Q 矩阵、答题、掌握度、诊断等 |
| 图数据库 | Neo4j：章节、知识点、归属与前置拓扑 |
| 学生端 | UniApp Vue 3，H5 + 微信小程序 |
| 管理端 | Vue 3 + Vite + Element Plus |
| 核心算法 | DINA + 拓扑约束下的多指标路径推荐 |
| LLM | 统一 service；解释/答疑/周报有规则降级 |

负责人已经明确延期以下事项，不作为本轮阻断：proposal 中的技术栈修改（负责人自行处理）、大学/计算机课程扩展、扩充到至少 500 个知识点、学习小组/讨论区、完整社交激励实现。当前用初中数学演示数据。智慧树仅作为信息架构和交互参考，不复制品牌和素材。

真实数据与个性化要求继续有效：学生取题不包含答案/解析，判题由服务端执行；学生个性化接口要求有效 student 身份；接口失败要有真实错误状态；路径顺序不能违反前置依赖。

配置与故障排查经验：

- 当前 Settings 来源优先级是“显式初始化参数 > `server/.env` > 进程环境变量 > 文件 secrets”。已定义在 `.env` 的键不能靠临时 `$env:...` 覆盖；测试故障应使用隔离配置，避免误伤现有服务。
- SQL Server 采用集成认证，无需索取 SQL 登录密码；`SECRET_KEY` 是应用 JWT 签名密钥，与 SQL 认证是两回事。
- 最新修复记录是 [SQL Server 连接反复失效根因与修复](../Delivery/2026-10-05-SQLServer连接反复失效根因与修复.md)：此前环境变量覆盖 `.env` 导致 TLS 信任失败，现已固定来源优先级；记录还说明受控机器证书已完成配置。新的环境应核对实际有效配置，避免直接照抄旧故障结论。
- 旧验收也出现过启动进程无法取得 Windows 集成身份而登录失败。健康/认证异常时检查有效配置、运行身份和日志，再决定是否重启；不要要求用户改为 SQL 密码认证。
- Neo4j `store_lock` 错误常见于对同一 data 目录启动了第二个实例。先查监听、进程和日志；不要删锁文件、批量结束 Java 进程或清空数据库。
- Python `httpx` 在本机曾因代理返回 502，而 PowerShell 直连正常。验收访问本机 API 可用 `trust_env=False` 排除系统代理，不能把代理错误直接归因于接口代码。
- 浏览器登录态、标签页、终端会话、临时变量不属于文件移交内容。新窗口应重新发现可用浏览器/服务并确认登录身份。旧窗口曾遇到浏览器控制工具初始化路径错误；已有截图可复核，但不能声称新的现场操作已经执行。
- [环境搭建指南](../环境搭建.md)存在历史描述（旧匿名接口、旧硬编码地址、初始化行为等），有冲突时按 V2、当前代码和 `server/sql/README.md` 判定。
