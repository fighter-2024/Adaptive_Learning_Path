## 退回原因

### P0：管理端业务页面没有进入构建产物

`admin/src/router/index.js` 使用拼接式动态导入：

```js
component: () => import('@/views/' + pascalCase(m.path) + '.vue')
```

Vite 无法静态收集这些模块。首次验收时 `npm run build` 虽退出 0，但构建目录只有 Login 分块，主 bundle 仍保留未解析的 `@/views/` 运行时导入。管理员登录后无法可靠打开业务页面。

### 证据不完整

未提交学生端和管理端的登录、刷新恢复、Token 失效、退出登录四条真实操作路径与截图。

## 必须修复

1. 将管理端路由改为 Vite 可静态分析的实现：
   - 推荐显式维护 `path → component` 映射；或
   - 使用 `import.meta.glob`，并对找不到页面的情况给出明确错误。
2. 保持 `menuRoutes` 与路由组件映射一致；不得依靠字符串猜测组件文件名。
3. 增加管理端路由烟雾验证，至少确认 `/dashboard`、`/knowledge-graph`、`/questions` 能成功加载对应 Vue 模块。
4. 检查学生端与管理端认证闭环：
   - Token 只从环境配置对应的后端取得；
   - 刷新后通过 `/auth/me` 恢复并校验角色；
   - 401 清理 Token 并进入登录页；
   - student Token 不能进入管理端，admin Token 不能进入学生端；
   - 退出后本地 Token 和用户信息均清理。
5. 请求错误必须保留可展示的 `status`、业务 `code` 和 `message`；不要为 M5 预先实现业务页面逻辑。

## 必测用例

- 路由构建产物中能找到 Dashboard、KnowledgeGraph、Questions 页面模块，且不再出现未解析的 `import('@/views/' + ...)`。
- 管理员登录后依次打开 `/dashboard`、`/knowledge-graph`、`/questions`，页面模块加载成功。
- 学生登录成功并刷新 H5，身份恢复成功。
- 伪造、过期 Token 被清理并跳转登录页。
- student Token 请求管理端受保护接口得到 403，不能进入管理页面。
- admin Token 在学生端校验后被拒绝，不作为学生身份使用。
- 学生端、管理端退出后刷新，仍保持未登录。
