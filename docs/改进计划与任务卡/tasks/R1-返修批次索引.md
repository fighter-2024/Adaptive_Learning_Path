## 统一复验规则

1. 执行者必须先阅读原任务卡、本返修卡、`docs/AI开发总则.md`、`API契约文档-v2.md`。
2. 只修复返修卡列出的缺陷；发现需要扩展契约时，先修改 V2 契约并说明兼容性。
3. 不得通过删除测试、降低断言、静默 catch、硬编码假数据或关闭构建检查获得通过。
4. 修复后重新执行原任务卡全部测试，不接受“只改了一行所以不用全测”。
5. 复验标题统一使用：`申请 M0 复验：M<number>-R1`。
6. 回报必须包含修改文件、契约变更、命令结果、真实操作证据、遗留风险；缺少证据直接退回。
