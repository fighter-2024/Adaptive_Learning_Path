# M1-R2 · 认证实证补交卡

## 可直接下发指令

```text
执行 docs/改进计划与任务卡/tasks/M1-R2-认证实证补交卡.md。
保留 M1-R1 已通过的显式路由实现，不扩展业务页面。启动可用后端后完成双端真实认证操作与截图，再申请 M0 复验：M1-R2。
```

## 必须补齐

- 学生端：登录、刷新恢复、伪造或过期 Token 清理、退出后刷新仍未登录。
- 管理端：管理员登录、刷新恢复、student Token 被拒绝、退出后刷新仍未登录。
- 证明 admin Token 不能作为学生身份使用。
- 401、403、断网三类界面表现；保留 `status`、业务 `code` 和 `message`。
- 浏览器真实打开 `/dashboard`、`/knowledge-graph`、`/questions`，不得只提供源码扫描。

## 自动化复验

```powershell
cd admin
npm run verify:routes
npm run build

cd ../frontend
npm run verify:auth
npm run build:h5
npm run build:mp-weixin
```

## 通过标准

命令全部通过，且每条真实路径都有可复现步骤和截图或录屏。不得提交真实 Token、密码或完整 Authorization 头。
