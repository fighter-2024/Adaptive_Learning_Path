# M5-R2 · 真实管理闭环实证补交卡

## 可直接下发指令

```text
执行 docs/改进计划与任务卡/tasks/M5-R2-真实管理闭环实证补交卡.md。
保留 M5-R1 已通过的原子保存、错误分类和图谱语义实现。在真实 Neo4j、SQL Server、后端和双端账号环境完成闭环证据，再申请 M0 复验：M5-R2。
```

## 前置条件

M1-R2 的真实登录和页面访问通过；M3-R2 的图谱语义通过。

## 必须提交的真实证据

1. 新建知识点 A，再新建 B 并把 A 设为 B 的前置；管理端刷新后关系存在，学生图谱同步变化。
2. 制造非法前置或环路；保存失败，并以刷新后的节点字段和关系证明没有半成功。
3. 新建题目并关联知识点；学生取题可见题干和选项，响应不含答案与解析。
4. 编辑题目关联知识点后，以只读查询或接口证明 Q 矩阵同步。
5. 批量导入至少一条成功、一条失败，页面显示成功数、失败数、行号和逐行原因。
6. 401、403、业务错误、断网四类界面截图。
7. course/chapter/knowledge_point、belongs_to/prerequisite、focus 及局部图提示截图。
