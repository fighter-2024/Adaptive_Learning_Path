# M4-R1：高密度图谱与交互证据补交卡

## 1. 背景

M4 核心实现、真实 API、三种视图和详情跳转已通过 M0 复验。当前只缺 M0 手册要求的现场交互及高密度可读性证据，本卡不新增业务范围，也不要求无依据地重构图谱组件。

## 2. 必须补交

1. H5 运行环境中依次展示：个性化路径、树状图谱、关系探索、节点详情和详情页跳转。
2. 在树状图谱中实际操作并截图或录屏：展开/折叠、缩放、拖拽、重置、适配画布。
3. 使用 `max_nodes>=80` 的真实或受控图谱数据，记录节点密集时的可读性；若响应出现 `meta.truncated=true`，必须展示局部结果提示且不能静默伪造完整图谱。
4. 在微信开发者工具或等价小程序运行环境展示一次树图或局部关系图，确认触摸操作和节点点击仍可用。
5. 复跑 `npm run build:h5`、`npm run build:mp-weixin` 及 M4 相关测试，附命令结果。
6. 若创建了临时用户或测试数据，交付中记录清理结果，不得污染业务库。

## 3. 交付物

- `docs/Delivery/2026-10-05-M4-R1-交互与高密度证据.md`
- 现场截图或录屏，至少包含上述 2～4 项。
- 命令输出和必要的 API 响应摘要（脱敏）。

## 4. 验收标准

- 现场操作可复现，截图/录屏能对应到具体动作，而非只有静态初始页面。
- 高密度图谱仍有清晰的层级、局部提示或可理解的降级行为。
- H5 与小程序构建不回归，相关测试通过。
- 没有硬编码题目、节点或假成功数据；临时数据已清理。
