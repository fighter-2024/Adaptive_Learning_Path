# M5 · 管理端知识图谱与题库页面

## 可直接下发指令

```text
执行 docs/改进计划与任务卡/tasks/M5-管理端知识图谱与题库页面.md。
先阅读 docs/AI开发总则.md、docs/改进计划与任务卡/API契约文档-v2.md 和综合改进要求。只完成管理端知识图谱与题库，不实现其他占位页。
完成后提供真实 CRUD 证据并申请 M0 验收 M5。
```

## 目标

替换管理端知识图谱和题库占位页，让管理员能够通过真实 API 管理知识点、前置关系、题目和 Q 矩阵。

## 优先级与依赖

- 优先级：P0
- 前置依赖：现有管理知识点/题目 API；图谱画布读取依赖 M3
- 可与 M1、M2、M3 并行开发表格和表单部分

## 必做范围

### 知识图谱页

- 左侧章节树；右侧知识点表格和图谱画布切换。
- 搜索、章节筛选、分页、加载/空/错误状态。
- 新增、编辑、删除知识点。
- 前置关系选择与全量保存。
- 删除前展示依赖影响；服务端拒绝时展示真实原因。
- 图谱画布支持聚焦、缩放、前置/后继高亮。

### 题库页

- 按知识点、题型、难度、关键词筛选和分页。
- 单选、多选、判断题编辑表单。
- 正确答案、解析、关联知识点和 Q 矩阵同步。
- 批量导入结果展示到成功/失败行，不只显示 toast。
- 删除和保存使用二次确认及明确错误信息。

## 不在范围

- 不实现仪表盘和学生数据页，交给 M6。
- 不实现社交管理。
- 不在前端绕过后端环检测和删除约束。

## 验收标准

- [ ] 两个页面不再包含占位文字或模拟表格。
- [ ] 知识点 CRUD 和前置关系保存真实落入 Neo4j。
- [ ] 图谱画布可读取 M3 接口并聚焦节点。
- [ ] 题目 CRUD 和 Q 矩阵同步落入 SQL Server。
- [ ] 批量导入能展示逐行失败原因。
- [ ] 401、403、业务错误和网络错误提示可区分。
- [ ] 管理端构建通过。

## 必须提交的证据

- 新建知识点并设置前置关系后，学生图谱变化截图。
- 新建题目后学生取题接口可见、但不泄露答案的证据。
- 批量导入含至少一条失败记录的结果截图。
- 管理端构建结果。
