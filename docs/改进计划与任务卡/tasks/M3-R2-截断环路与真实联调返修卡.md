## 必须修复

当前拓扑加载只取“目标位于 selected_ids”的边，环的一部分若落在窗口外会被遗漏。必须保证与当前查询范围相关的完整图存在环时，tree/network/personalized 不返回成功的部分图或推荐。

可采用 Neo4j 侧有界环检测、独立只返回布尔/路径的环检测查询，或其他不把全图属性加载进 Python 的实现。错误继续映射为 `50002`，不得静默降级为空图。

## 必须新增测试

- 选中 A、窗口外 B，完整关系为 `A → B → A`，请求必须报图数据库错误。
- 环完全位于渲染窗口内继续报错。
- 无环但存在窗口外直接前置时，locked 与推荐阻断仍保持 R1 结果。
- 环检测不得引入逐节点查询或把全图节点属性拉回 Python。
