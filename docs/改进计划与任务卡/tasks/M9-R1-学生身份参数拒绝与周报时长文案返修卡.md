## 1. P1：按 V2 拒绝他人身份参数

冻结契约要求任何传入他人 `student_id` 的学生请求返回 `40101`。当前四条 query 均 200/code0；诊断 body 也 code0；聊天两条 body 为 422/40000。本轮没有跨学生数据泄露证据，但不能把忽略参数或普通字段错误算作契约通过。

限定新增四个 M9 路由：

- POST `/api/student/diagnosis/explain`
- POST `/api/student/chat`
- POST `/api/student/chat/knowledge-point`
- GET `/api/student/weekly-report`

要求：

- [x] 先完成正式 `require_student` 鉴权；无/无效/过期 Token 401/40100，admin Token 403/40101，继续有效。
- [x] 有效学生在 query 或 POST JSON body 传入另一学生 `student_id` 时，明确 403/40101；不能被忽略，也不能先由 extra-forbid 转为 422/40000。各渠道有冲突/重复参数时不能绕过越界拒绝。
- [x] 未传身份参数时保持现有合法请求；传同一身份也不能成为任意读取他人的入口，服务端始终只使用认证 `user.user_id`。同身份参数的兼容选择在交付说明中写清。
- [x] 普通业务字段非法/超长/历史结构错误保持既有校验，未知知识点维持真实错误，不放宽聊天 extra/system 权限。
- [x] 拒绝发生在业务读写/模型调用前，不产生他人或本人的多余报告、诊断及模型请求。

不修改 V2 来适配当前错误行为；不重写全局 optional 鉴权、不重开已关闭的 M8-R2，不改路径算法、配置原子性或认证体系。若确有不可兼容冲突，向 M0 提交具体冲突，不能自行放宽契约。

## 2. P2：区分不足一分钟与记录缺失

真实页面三次作答合计有效时长 20 秒，统计按当前口径为 0 分钟；模型却称“未包含有效时长数据”。只改总结所需上下文、Prompt/事实校验与规则兜底，不改真实统计定义。

- [x] 提供有效原始秒数或等价明确事实及分钟取整语义，区分“0 秒/没有有效记录”与“正值但不足 1 分钟”；模型只负责总结。
- [x] 对正值不足一分钟的总结设置明确事实约束及校验/兜底，不能声称无有效时长。可以表达“已记录的作答时长不足 1 分钟，按整分钟显示为 0”。
- [x] 维持 `study_time_minutes` 原口径、重复作答计数、历史快照、用户/周缓存隔离；不把作答时长写成总学习时间。
- [x] Prompt/上下文或校验规则改变后旧摘要缓存应失效，不能继续命中这份错误正常报告；保留成功/降级 TTL 和数据/配置失效。
- [x] 不把学生身份、Token、密码、答案明细加入 provider 上下文；正常响应/规则降级的字段契约继续有效。
