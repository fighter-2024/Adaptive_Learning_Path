# M4 · 学生端图谱与个性化路径可视化

## 可直接下发指令

```text
执行 docs/改进计划与任务卡/tasks/M4-学生端图谱与个性化路径可视化.md。
先阅读 docs/AI开发总则.md、00-范围与决策、01-综合改进要求以及 docs/改进计划与任务卡/API契约文档-v2.md。
实现学生端真实图谱与路径交互，完成后提交 H5/小程序证据并申请 M0 验收 M4。
```

## 目标

参考智慧树的信息架构，将现有纵向路径卡片升级为“个性化路径 + 课程树图 + 局部关系探索”，突出自适应学习主题。

## 优先级与依赖

- 优先级：P0/P1
- 前置依赖：M1、M3
- 可与 M6、M7 并行

## 必做范围

1. 学生端提供三个一级视图：
   - 我的学习路径（默认）；
   - 课程图谱；
   - 关系探索。
2. 个性化路径使用方向箭头、序号、掌握率和推荐理由；突出“当前”和“下一步”。
3. 树图支持章节折叠/展开和节点懒加载。
4. 关系探索默认只展示 focus 节点 1～2 层邻居。
5. 支持拖动、缩放、复位、适应视图、图例和搜索。
6. 节点点击打开详情卡片，提供跳转知识点详情或开始答题入口。
7. 颜色只表示掌握状态，形状表示 course/chapter/knowledge_point。
8. 节点过多时显示局部图提示和缩略导航。
9. H5 可使用经批准的 `@antv/g6`；安装前在交付说明中记录必要性和包体影响。
10. 微信小程序首版允许使用简化路径/树图降级，不得为了全图擅自引入第二套大型图引擎。

## 不在范围

- 不实现环图。
- 不复制智慧树品牌、图标、AI 人物或视觉素材。
- 不在前端计算推荐算法。
- 不在画布中提供管理员编辑能力。

## 体验要求

- 进入页面 2 秒内必须有 loading/骨架反馈。
- 首屏最多 80 个节点，超出必须分层加载。
- 标签过长时换行或省略，不能大面积互相遮挡。
- 页面返回再进入时保留合理的 focus，但不得缓存其他用户的 mastery。
- 接口错误提供重试入口。

## 验收标准

- [ ] 默认打开个性化路径，而不是全量网图。
- [ ] 三种视图均使用真实 API 数据。
- [ ] 点击树节点能展开或加载下一层。
- [ ] 点击知识点能查看掌握度、理由并跳转详情。
- [ ] 图例与实际颜色/形状一致。
- [ ] H5 缩放、拖动、复位正常。
- [ ] 小程序有明确、可用的降级展示。
- [ ] H5 和小程序构建通过。

## 必须提交的证据

- 三种视图截图或短录屏。
- 一个节点展开、一个局部关系高亮、一个详情跳转操作路径。
- 80 节点以上模拟数据的可读性说明。
- 新依赖体积和平台兼容说明。
