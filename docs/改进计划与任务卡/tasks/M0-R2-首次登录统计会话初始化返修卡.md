## P2：正式登录成功后统计仍判定会话无效

真实新构建 H5 和新 uvicorn/PID38488，空登录态启动后：

1. A 正式 `/auth/login`、`/auth/me` 均成功，“我的”页显示正确账号和学生 ID。
2. 首页与我的页统计却提示“当前登录状态无效，请重新登录”，重试仍失败，首页姓名显示“同学”。
3. 整页刷新后立即恢复真实知识点统计；已有两条作答时首页为 2/22=9%，我的页已掌握 2。
4. 保留 A 数据，A退出→点击首页触发正常登录页→B登录，同样误报无效；刷新后 B 才显示自身 0%/已掌握 0。

这不是后端 Token 失效，也不能要求用户每次登录后刷新来绕过。

## 根因与最小边界

`initializeSession()` 使用 `initializationPromise = (async () => { ... })()`。没有 Token 时，内部在第一次 await 之前同步 return false，finally 同步设置 initializationPromise=null；随后外部赋值又写回已完成的 false Promise。后续 ensureAuthenticated() 一直复用该旧结果。`login()` 成功更新真实用户和 Token 后也未消除这个残留。

M02 对当前源码的受控行为复现得到：初始 false → login 后 isLoggedIn=true → ensureAuthenticated(false) 仍 false；没有修改源码或使用真实凭证。真实页面和日志证明同一结果。

要求修正 Promise 的创建/赋值/完成清理时序，保证无 Token、失败、成功均能结束本批初始化；不缓存旧身份或旧结果，不允许旧请求覆盖/清除新账号的会话。保留并发初始化复用和 `/auth/me` 角色验证；不得用“已有本地 Token 即通过”或忽略失败解决。
