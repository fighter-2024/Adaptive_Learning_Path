# 🧠 自适应学习路径规划与社交激励系统 — 讨论会大纲

> **本大纲为 Phase 0 讨论会的历史快照**。第九节「待讨论 / 待决策事项」中的事项后续均已定稿：

## 一、项目背景与目标

- 省级大创项目定位
- 核心愿景：基于知识图谱，为每位学员生成个性化学习路径，辅以社交激励
- 两套角色视角：**学员端**（学习 + 社交）+ **管理端**（运营 + 诊断）

## 二、技术栈总览

| 层面 | 选型 | 说明 |
|------|------|------|
| 后端 | Python FastAPI | REST API，统一服务 |
| 图数据库 | Neo4j | 知识点关系存储 & 路径查询 |
| 关系库 | SQL Server | 用户/答题/社交数据 |
| 学员前端 | UniApp | 一套代码 → H5 网页 + 微信小程序 |
| 管理后台 | Vue 3 SPA | 独立工程 `admin/` |
| 认知诊断 | DINA 模型 | Q矩阵 + EM + 贝叶斯后验 |
| 路径规划 | 拓扑排序 + 多指标贪心 | |
| AI 能力 | LLM API | 诊断解读 / 错题归因 / 周报 |

## 五、功能模块划分

## 六、核心算法路线

```
学生答题记录
    │
    ▼
DINA 认知诊断 ──→ 估计 slip/guess (EM) ──→ 贝叶斯推断掌握向量 α
    │
    ▼
知识图谱 (Neo4j) + α 向量
    │
    ▼
路径规划 ──→ 拓扑排序保序 ──→ 多指标贪心打分（距离目标 / 掌握概率 / 难度 / 时长）
    │
    ▼
推荐学习路径 → 前端展示 + AI 解读
```

---

## 七、AI 接入点

1. **诊断结果解读** — 把 α 向量翻译成人话
2. **路径推荐解释** — 为什么推荐这条路
3. **错题归因分析** — 哪没掌握、为什么错
4. **学习周报生成** — 本周学了什么、进步在哪
5. **知识点提取辅助** — 从教材自动抽取知识点（可选）

## 八、开发规范（已定）

- 算法先跑 Jupyter Notebook → 成熟后移植到 `server/app/services/`
- API 统一返回格式：`{"code": 0, "data": ..., "message": ""}`
- 后端代码注释中文，标识符英文
- 配置全部走环境变量 `.env`，不硬编码密钥
