# M8 学习路径算法可配置、可解释与联动交付说明

## 实现范围

- 路径四项权重从 service 常量迁移到 `Settings` 和运行时配置快照，默认 profile 为 `default-v1`，算法版本为 `greedy-v1`；权重要求均在 `0..1` 且总和为 `1`。
- `GET/PUT /api/admin/config` 已接通管理端配置页。API Key 只返回掩码，空值表示不修改；运行时更新不会写入仓库，部署持久化仍通过 `.env`。
- 路径步骤保留原有字段，并增加 `status`、`locked`、`reason_codes`、`score_components`；路径 `meta` 返回算法版本、profile、权重、掌握数据来源和降级标记。
- 推荐前先对完整知识图谱执行拓扑排序；即使环路经过已掌握知识点，也会拒绝生成路径。
- SQL Server 掌握快照读取失败时返回可用但明确标记 `degraded=true` 的非个性化路径，不再静默伪装成“全部未开始”。无快照则以 `mastery_source=no_data` 和 `NO_MASTERY_DATA` 标识。
- 学生端路径页展示掌握率、当前/下一步状态、推荐理由，并在掌握数据降级时展示提示；答题或诊断返回后沿用现有 `onShow` 刷新联动。

## 证据

### 两组权重排序变化

测试用例使用两个无前置知识点：`easy`（掌握度 0.50、难度 0.10、10 分钟）和 `weak`（掌握度 0.10、难度 0.90、60 分钟）。

| profile | 掌握度 | 目标距离 | 难度 | 时间 | 首步 |
|---|---:|---:|---:|---:|---|
| `default-v1` | 0.40 | 0.30 | 0.20 | 0.10 | `easy` |
| `mastery-first-v1` | 0.90 | 0.05 | 0.03 | 0.02 | `weak` |

### `score_components` 示例

```json
{
  "mastery": 0.32,
  "target_distance": 0.20,
  "difficulty": 0.08,
  "time_cost": 0.011111,
  "total": 0.611111
}
```

对应默认权重下的掌握度 0.20、难度 0.60、40 分钟、距目标 1 跳步骤；每项均为“指标得分 × 配置权重”。
