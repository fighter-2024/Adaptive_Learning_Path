## 修复内容

- 四个学生 AI 路由现在统一检查 query 和 JSON body 中的 `student_id`。有效学生传入他人身份、或 query/body 冲突时，在业务服务和模型调用前返回 HTTP `403`、业务码 `40101`；无身份参数保持原行为，同身份参数仅作兼容，业务始终使用 JWT 的 `user_id`。
- 鉴权依赖仍先于身份参数检查：匿名、无效、过期凭证为 `401/40100`，管理员凭证为 `403/40101`。
- 周报上下文增加原始秒数和明确的作答时长事实。正值不足一分钟会保留“已记录作答时长 N 秒，不足 1 分钟，按整分钟显示为 0 分钟”的事实；模型作出“没有有效时长”等矛盾表述时进入规则兜底。`study_time_minutes`、重复作答、快照和周缓存口径保持不变；源数据或 Prompt 摘要指纹变化会使旧摘要失效。
