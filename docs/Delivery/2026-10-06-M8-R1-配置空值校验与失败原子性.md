# M8-R1 交付说明：配置空值校验与失败原子性

日期：2026-10-06

## 结论

M8-R1 技术返修已完成，申请 M0 复验：M8-R1。此次只修改管理端系统配置更新链路及其测试/契约证据；既有路径权重算法、拓扑检测、解释字段和降级语义保持不变。

## 修复内容

- `PUT /api/admin/config` 区分字段省略和显式 `null`。除 `llm_api_key` 外的所有可更新字段显式 `null` 均返回统一业务码 `40000`，不会抛出未捕获 `500`。
- `llm_api_key` 的 `null`、空串和省略均表示不修改；非空密钥只写入运行时配置，响应和异常路径都不回显原文。
- 更新流程改为候选快照：先合并请求、校验完整配置（类型、范围、profile、四权重总和、超时等），并预先通过安全响应模型校验，全部通过后才提交 settings。
- 候选校验失败时，合法字段不会提前生效；赋值异常也有回滚保护。失败后的 GET、路径算法配置快照和诊断参数仍可用。

## 独立复现结果

在 `server` 工作目录执行：

```powershell
$env:PYTHONPATH='.'
python scripts/m01_verify_m8_config_null.py
```

脚本覆盖全部非密钥可更新字段的 `null`、密钥 `null`/空串、非法权重、空 profile 以及合法字段与 `null` 混合更新。每个案例都比较 PUT 前后的完整运行时 settings 快照，并确认随后 GET 为 `HTTP 200 / code 0`。非法更新均为 `HTTP 200 / code 40000`，密钥空值为 `HTTP 200 / code 0` 且保持原值。
