# M6 管理端仪表盘与学生数据看板交付说明

## 已实现

- `GET /api/admin/dashboard/summary`
  - 学生总数、启用题目总数、Neo4j 知识点总数；
  - 本周活跃学生：本周一以来 `answer_records` 与 `diagnosis_sessions` 的去重学生数；
  - 最近诊断及 alpha 向量平均掌握度。
- `GET /api/admin/students`
  - 按学生 ID、账号、姓名搜索；
  - 分页返回答题数、掌握知识点数、平均掌握度和最近活跃时间。
- `GET /api/admin/students/{student_id}`
  - 基本信息；
  - SQL Server 掌握快照与 Neo4j 知识点名称；
  - 最近诊断会话摘要和最新 alpha 向量；
  - 最近 50 条答题时间线；
  - 复用现有拓扑约束推荐算法生成当前推荐路径；
  - `meta` 标注答题/诊断历史限制和跨库数据来源。
- 管理端 `Dashboard.vue` 和 `Students.vue` 已从占位页改为真实 API 看板。学生详情默认薄弱项优先，并提供全部知识点切换，不使用不可读的大型雷达图。
- 所有新增管理路由挂载 `require_admin`；学生 Token 访问返回 403。
