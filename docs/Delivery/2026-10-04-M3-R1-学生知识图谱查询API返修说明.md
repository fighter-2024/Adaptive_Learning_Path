# M3-R1 学生知识图谱查询 API 返修说明

## 1. 返修内容

- `focus_id` 在 `max_nodes=1/2/3` 等极小窗口下始终保留，并置于稳定结果的首位。
- 焦点邻居按 Neo4j 最短距离和知识点 ID 稳定排序，避免结果随数据库返回顺序漂移。
- 候选总数、章节数和有界候选选择下推到 Neo4j；`include_mastered=false` 在数据库候选范围内排除已掌握知识点后再计数。
- 图谱渲染窗口外的直接前置知识点保留为约束拓扑，参与 `locked` 和推荐顺序计算，但不作为渲染节点返回。
- SQL Server 掌握度查询改为分批参数化查询，避免大规模 `IN` 参数超过限制，并保持学生隔离。
