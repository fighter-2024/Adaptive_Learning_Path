# M3 学生知识图谱查询 API 交付说明

## 1. 实现范围

- `GET /api/student/graph`：支持 `tree`、`network`、`personalized`、`focus_id`、`depth`、`max_nodes`、`include_mastered`。
- `GET /api/student/graph/{id}/neighbors`：支持 `incoming`、`outgoing`、`both`，并在一次 Neo4j 子图查询中读取邻居。
- `GET /api/admin/graph`：支持章节、关键词、焦点和深度过滤；学生字段全部为 `null`。
- 新增统一 Pydantic 模型：`GraphNode`、`GraphEdge`、`GraphMeta`、`GraphData`。
- 课程根节点由 service 生成；章节节点和 `BELONGS_TO`、`PREREQUISITE` 边来自 Neo4j。

学生图谱只接受有效 student Token，管理图谱由 admin router 的权限依赖保护。SQL Server 异常返回 `50001`，Neo4j 异常返回 `50002`，不会伪装成成功空图。

## 3. 验证证据

执行：

```text
cd server
python -m pytest -q
```

结果：`292 passed`。

M3 专项测试覆盖：

- 缺少 student Token 返回 HTTP 401 / `40100`；非法 focus 返回 `40400`。
- `incoming` 方向、深度和 `max_nodes` 参数传递。
- 500 个模拟知识点的截断：`returned_nodes == len(nodes) == 80`，`truncated == true`，`total_nodes` 含课程根和章节节点。
- personalized 合并掌握概率、状态、推荐顺序和理由。
- 管理端学生字段为 `null`。
- Neo4j/SQL Server 异常分别抛出并由 router 映射为 `50002`/`50001`。

`_db_query_mastery_map` 使用一次 `WHERE user_id = ? AND knowledge_point_id IN (?, ...)` 查询；专项测试记录调用次数为 1、传入 500 个知识点 ID，未按节点逐条查询 SQL。
