### 4.2 Review

两次 Review 均通过，最终结论 **ship as-is**：

- `PaginatedData.list` + `typing.List` 无名称冲突
- JSON 序列化字段名 `"list"` 与 API 契约一致
- 无别名嵌套问题
- 测试覆盖充分

## 五、Review 中发现并修复的问题

| # | 问题 | 修复 |
|---|------|------|
| 1 | `PaginatedData` 字段名 `list` 与 builtin 冲突 | 改用 `typing.List[T]` 泛型 + `# noqa: A003` |
| 2 | `settings.py` 使用弃用的 `class Config` | 迁移到 `model_config = SettingsConfigDict(...)` |
| 3 | `main.py` 使用弃用的 `@app.on_event("shutdown")` | 迁移到 `lifespan` context manager |

## 七、启动方式

```bash
cd server
cp .env.example .env      # 填入真实的 Neo4j / SQL Server / LLM 连接信息
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

### 可访问的端点

| 路径 | 说明 |
|------|------|
| `http://localhost:8000/` | 根路径 |
| `http://localhost:8000/health` | 全局健康检查（含 Neo4j + SQL Server 状态） |

| `http://localhost:8000/api/student/health` | 学员端健康检查 |
