## 完成内容

- 统一 `llm_service`：DeepSeek/通义兼容接口、配置快照、共享总超时、最多 2 次重试、输出校验、固定分类日志和规则降级。
- 集中维护诊断、答疑、周报和路径解释 Prompt；模型只负责解释文字，不能修改掌握度、题目答案或路径拓扑。
- 完成学生端 `POST /api/student/diagnosis/explain`、`GET /api/student/path/explain`、`POST /api/student/chat`、`POST /api/student/chat/knowledge-point`、`GET /api/student/weekly-report`。
- 诊断优势/薄弱标签由真实诊断概率计算；模型只能生成 `explanation` 与 `suggestion`。
- 答疑只注入必要知识点资料，关联 ID 由服务端图谱白名单核实；前端历史按学生和知识点隔离，失败消息不写入历史，关联卡片可跳转知识点详情。
- 周报统计来自 SQL Server 作答记录和诊断/掌握快照，重复作答按尝试计数；同一学生同一周持久化缓存，数据、模型配置或缓存 TTL 变化时失效。作答时长与总学习时长严格区分。
- 完成学生端诊断解读、答疑、周报页面和管理端 AI 报告分页、学生/周筛选、报告抽屉。
