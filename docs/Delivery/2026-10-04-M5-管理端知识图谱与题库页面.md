# M5 · 管理端知识图谱与题库页面交付记录

**交付日期**：2026-10-04  
**范围**：仅管理端知识图谱与题库页面；未实现 M6 仪表盘、学生数据和社交管理。

## 交付内容

| 文件/模块 | 内容 |
|---|---|
| `admin/src/views/KnowledgeGraph.vue` | 章节目录、搜索/分页、知识点 CRUD、前置关系全量保存、删除依赖影响确认、表格/图谱切换、聚焦/缩放/关系高亮 |
| `admin/src/views/Questions.vue` | 知识点/题型/难度/关键词筛选、分页、单选/多选/判断编辑、答案/解析、Q 矩阵同步、删除确认、逐行批量导入结果 |
| `admin/src/utils/request.js` | 区分 401、403、业务错误、限流、网络/超时和服务端错误，供页面展示可读失败状态 |
| `server/app/routers/admin/graph.py` | `GET /api/admin/graph`，按契约支持章节、关键词、focus、depth、max_nodes |
| `server/app/routers/admin/__init__.py` | 注册管理员鉴权的图谱读取路由 |
| `server/tests/test_admin_graph.py` | 图谱 service 组装和管理端路由统一响应测试 |

现有知识点 CRUD、题目 CRUD/Q 矩阵事务和批量导入 service 未被前端绕过；页面均通过统一 request 封装调用真实 API。
