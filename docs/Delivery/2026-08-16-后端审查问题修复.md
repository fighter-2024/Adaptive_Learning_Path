## 二、日志要求落实（本次修复全程记日志）

按总则「禁止 print，用 logging」，所有修复点均带日志：

- 触发速率限制 → `logger.warning`（含 key、窗口、次数、上限，用于审计暴力破解）
- 密码哈希格式异常 → `logger.warning`（不泄露给客户端）
- 更新 last_login_at 失败（含建连失败）→ `logger.warning`（不再产生 Task exception 告警）
- CORS 最终配置 → 启动时 `logger.info`（origins + allow_credentials）
- 可选身份解析失败 → 仅异常摘要 warning（降噪）
- 知识图谱/题库历史脏数据兜底、Q 矩阵校验失败 → 均有 warning/error 日志
- 触发限流/鉴权失败的响应均保持统一 `{code, data, message}` 格式
