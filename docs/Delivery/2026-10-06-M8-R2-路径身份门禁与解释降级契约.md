## 修复内容

- `GET /api/student/path` 与 `GET /api/student/path/explain` 改用既有 `require_student` 依赖。
  无 Token、无效/过期 Token 返回 HTTP 401 / `40100`；admin Token 返回 HTTP 403 / `40101`；有效 student Token 始终使用当前 Token 对应的 `user_id`。
- `PathExplainData` 增加 `degraded` 与 `degraded_reason`，正常成功固定返回 `false/null`。
- 解释服务直接返回包含业务降级元数据的模型，router 不重写业务语义。
- LLM 未配置、失败、空响应、超长响应或结构异常时继续返回规则解释，并标记“大模型解释不可用，已使用规则解释”。
- SQL Server 掌握数据读取失败时，`path` 与 `path/explain` 均标记掌握数据降级原因；若同时发生 LLM 降级，原因会安全合并，不暴露内部异常或密钥。
- 未修改全局可选身份辅助函数，保留其他历史只读接口行为；权重、打分、拓扑、主路径 SQL 降级和 M8-R1 配置链路不变。
