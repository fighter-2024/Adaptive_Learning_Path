## 一、交付内容

严格对照 `docs/API契约文档.md`「2.1 学习」，在 `server/app/routers/student/` 下实现学员端知识点接口 2 个：

| 接口 | 说明 | 契约章节 |
|------|------|----------|
| `GET /api/student/knowledge-points` | 学员视角知识点列表（含每个知识点的 `mastery_probability` 和 `status`） | 2.1 |
| `GET /api/student/knowledge-points/{id}` | 知识点详情（含前置知识点掌握状态 + 关联题目列表） | 2.1 |

### status 枚举（按契约阈值）

| status | 条件 |
|--------|------|
| `mastered` | mastery_probability ≥ 0.8 |
| `learning` | 0.4 ≤ mastery_probability < 0.8 |
| `weak` | mastery_probability < 0.4 |
| `not_started` | 无掌握数据（user_kp_mastery 无该学员记录） |

### 响应结构要点（与契约逐字段一致）

- 列表接口：`data` 为 `{list: [...]}`，**非分页结构**（契约中无 total/page/page_size，未自行添加）。
- 详情接口：`data` 含 `id/name/description/difficulty/estimated_time/mastery_probability/prerequisites/questions`；`prerequisites` 元素为 `{id, name, mastered}`，`questions` 元素为 `{id, content, type, difficulty, done}`。
- 学员视角不返回题目答案与解析（避免泄题）。

## 三、关键设计决策

### 1. 数据来源（严格遵守总则第六条「数据库职责划分」）

| 数据 | 来源 |
|------|------|
| 知识点基础信息（id/name/description/difficulty/estimated_time/chapter_name） | Neo4j `KnowledgePoint` 节点 + `Chapter` 节点 |
| 前置依赖拓扑 | Neo4j `(前置)-[:PREREQUISITE]->(当前)` 入边 |
| 学员掌握概率 `mastery_probability` | SQL Server `user_kp_mastery` 快照表 |
| 关联题目 | SQL Server `q_matrix` + `questions`（is_active=1） |
| 题目是否已做 `done` | SQL Server `answer_records`（有作答记录即 done，不区分对错） |

### 2. 学员身份（认证暂未全局启用的过渡方案）

学员端 JWT 认证按现有代码约定（`routers/student/__init__.py` 占位说明）暂未全局启用。本次通过新增的 **`get_current_user_optional`** 可选身份解析提前兼容：

- 携带有效 `Authorization: Bearer <token>` → 按该学员视角返回个性化掌握数据；
- 未携带 / Token 无效 → 降级为匿名视角（`mastery_probability` 为 null、`status` 为 `not_started`、前置均未掌握、题目均未做），不返回 401。

全局认证开启后（在 student router 统一挂 `Depends(require_student)`），接口行为自动变为纯学员视角，无需改动业务代码。

### 3. 降级策略（沿用既有惯例，不阻塞业务流程）

- **SQL Server 异常**：掌握概率降级为 null（→ not_started）、`done` 降级为 false、题目列表降级为空，记录 warning 日志；
- **Neo4j 异常**：向上抛，由 router 统一映射为 `code=50002`「图数据库异常，请稍后重试」（不暴露内部堆栈）；
- **知识点不存在**：`code=40400`「知识点不存在」。

### 4. 边界值处理

- `status` 计算为纯函数 `compute_mastery_status`，边界 0.8→mastered、0.4→learning、<0.4→weak（含单测锁定）；
- 前置 `mastered` = 该前置知识点掌握概率 ≥ 0.8（无数据为 false）；
- Neo4j 历史导入数据缺属性时（difficulty/estimated_time 为 null）给默认值 0.0/0，保证模型校验不崩。
