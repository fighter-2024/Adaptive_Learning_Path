# UI 功能分类

> 按核心功能与高级功能分类，标注每个页面/模块的用途和优先级。

---

## 一、客户端（UniApp · 学员端）— 13 个页面（8 核心 + 5 高级；另有 1 个详情页内嵌问答）

### 核心功能（8 页）

| 页面 | 路由 | 功能说明 | 优先级 |
|------|------|------|:--:|
| 首页 | `pages/index/index` | 今日任务卡片、连续打卡天数、学习进度环、快捷入口 | P0 |
| 学习总览 | `pages/learning/index` | 章节折叠面板，知识点列表按掌握状态色标显示（绿/黄/红/灰） | P0 |
| 知识点详情 | `pages/learning/detail` | 知识点描述/难度/时长、前置知识点状态、关联题目列表、底部「开始答题」按钮 | P0 |
| 答题页 | `pages/quiz/quiz` | 单选/多选/判断三种题型，提交后显示对错+解析，进度条，逐题模式 | P0 |
| 学习路径 | `pages/path/path` | 时间轴步骤条展示推荐学习序列，每步显示知识点名/难度/原因，点击跳转详情 | P1 |
| 诊断总览 | `pages/diagnosis/index` | 各知识点掌握概率可视化（进度条/雷达图）、上次诊断时间、「重新诊断」按钮 | P1 |
| AI 答疑（通用） | `pages/chat/index` | 自由对话，消息气泡 + markdown 渲染，关联知识点卡片可跳转，历史本地存储 | P1 |
| 周报 | `pages/report/report` | 数据卡片（答题数/正确率/学习时长）、新掌握知识点、薄弱知识点、AI 总结 | P1 |

### 高级功能（5 页 + 1 个内嵌功能）

| 页面 | 路由 | 功能说明 | 优先级 |
|------|------|------|:--:|
| AI 解读 | `pages/diagnosis/explain` | 完整 AI 诊断评语、优势/薄弱知识点标签、学习建议 | P2 |
| 知识点内嵌问答 | 内嵌于详情页 | 知识点详情页底部「🤖 问 AI」悬浮按钮，半屏对话，上下文限定当前知识点 | P2 |
| 社交首页 | `pages/social/index` | 排行榜（周/月/总榜切换）、每日打卡按钮 | P3 |
| 成就列表 | `pages/social/achievements` | 已解锁成就展示 + 未解锁成就进度条 | P3 |
| 我的 | `pages/mine/index` | 个人信息、成就入口、历史周报入口、设置入口 | P3 |
| 设置 | `pages/settings/index` | 修改昵称、修改密码、退出登录 | P3 |

---

## 二、管理后台（Vue 3 · 管理员端）— 8 个页面（7 个菜单页 + 学生详情；另有 2 个内嵌弹窗）

### 核心功能（4 页）

| 页面 | 路由 | 功能说明 | 优先级 |
|------|------|------|:--:|
| 仪表盘 | `/dashboard` | 4 个统计卡片（学生数/题目数/知识点数/周活跃）、最近诊断概览表 | P0 |
| 知识图谱管理 | `/knowledge-graph` | 左侧章节树 + 右侧知识点表格、新增/编辑/删除知识点、前置关系穿梭框设置 | P0 |
| 题库管理 | `/questions` | 筛选栏（知识点/题型/难度/搜索）、题目表格（分页）、新增/编辑全屏弹窗、批量导入 | P0 |
| 学生数据 | `/students` | 学生列表（分页+搜索）、点击进入详情（雷达图 + α 向量 + 答题时间线） | P1 |

### 高级功能（4 页 + 2 个内嵌弹窗）

| 页面 | 路由 | 功能说明 | 优先级 |
|------|------|------|:--:|
| 学生详情 | `/students/:id` | 知识点掌握雷达图（ECharts）、答题历史时间线、α 向量进度条 | P2 |
| 社交管理 | `/social` | 成就定义 CRUD（名称/条件/图标）、打卡记录按日期/学生查询 | P3 |
| AI 报告 | `/ai-reports` | 按学生/周筛选周报列表、点击查看完整周报（数据卡片+AI总结文字） | P3 |
| 系统配置 | `/config` | DINA 参数表单 + LLM 参数表单，加载/保存 | P2 |
| 题目编辑弹窗 | 内嵌于题库管理 | 动态选项编辑、题型切换、关联知识点多选 | P0 |
| 知识点编辑弹窗 | 内嵌于知识图谱管理 | 知识点表单 + 前置关系管理 | P0 |

---

## 三、优先级说明

| 优先级 | 含义 | 对应时间 |
|:--:|------|------|
| P0 | 系统最低可运行闭环，缺了跑不通 | Phase 2（第 5-9 周） |
| P1 | 核心竞争力功能，缺了不完整 | Phase 2-3 |
| P2 | AI 增强体验，锦上添花 | Phase 3（第 10-13 周） |
| P3 | 社交激励，可演示但非必需 | Phase 3-4 |

---

## 四、最小可演示版本

如果时间紧张，砍到 **核心功能 P0 + P1** 即可拿出一个完整的系统闭环：

```
学员端：首页 → 学习总览 → 知识点详情 → 答题 → 诊断总览 → AI答疑 → 周报
                └→ 学习路径 ─┘

管理后台：仪表盘 → 知识图谱管理 → 题库管理 → 学生数据
```

**学员端核心闭环 8 页 + 管理后台核心 4 页 = 12 页**，足够演示和答辩。高级功能可以在后续迭代中逐步加入。
